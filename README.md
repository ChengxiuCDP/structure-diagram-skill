# structure-diagram

A Claude Code skill for reasoning about and implementing structural diagrams as inline SVG.

The skill includes a reusable reference example plus scripts for checking SVG geometry and rendering SVG to PNG without browser automation.

## Install for Claude Code

Clone this repository into `~/.claude/skills/structure-diagram`:

```bash
git clone https://github.com/ChengxiuCDP/structure-diagram-skill.git ~/.claude/skills/structure-diagram
```

Restart Claude Code or start a new session to discover the skill.
